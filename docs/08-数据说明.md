# 08 数据说明

## 当前状态

本项目当前**没有数据集、标注文件、模型权重、数据库或对象存储**。`data/` 仅用于后续规范化存放获得授权的数据，不应被当作已具备训练或评测条件。

## 当前数据流

| 内容 | 来源 | 去向 | 是否保存 |
| --- | --- | --- | --- |
| 单图 | 用户本机选择 | 后端请求内存 | 否 |
| 摄像头帧 | 用户浏览器 | 后端请求内存 | 否 |
| Mock 结果 | 后端生成 | 浏览器 LocalStorage | 仅本机 |
| 人工复核 | 用户操作 | 浏览器 LocalStorage | 仅本机 |

## 后续数据目录建议

```text
data/
  raw/           # 获得授权的原始图像
  annotations/   # 标注文件和标注规范版本
  processed/     # 清洗、脱敏后的数据
  splits/        # 训练、验证、测试集划分清单
  manifests/     # 数据来源、许可证、校验和清单
```

实际数据文件应保持 Git 忽略，只提交数据说明、版本号、许可证和可复现清单。

## 引入数据前的最低要求

1. 明确数据提供方、使用授权和保留期限。
2. 定义划痕类别、标注边界和难例标注规则。
3. 固化训练、验证、测试集划分，避免同源图像泄漏。
4. 记录采集设备、光照、钢种和表面状态等背景信息。
5. 未完成以上步骤前，不应公开任何模型精度结论。
