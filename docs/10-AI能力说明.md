# 10 AI 能力说明

## 总体原则

当前系统只实现了模型接口契约和 Mock 返回，没有加载真实检测模型，不读取数据集，也不提供准确率、召回率、mAP、FPS 等性能声明。

## 当前 Mock 推理

- 服务位置：`backend/app/services/inference.py`。
- 行为：根据文件名生成稳定的演示结果；包含 `normal`、`good`、`ok`、`无划痕`、`正常` 的文件名会返回空预测。
- 输出：模型名称、版本、置信度、百分比坐标框和模拟耗时。

## 模型契约

| 字段 | 约定 |
| --- | --- |
| `class_name` | 缺陷类别，例如 `Scratch` |
| `confidence` | 0–1 之间的置信度 |
| `bbox` | `x1/y1/x2/y2`，范围 0–100 的百分比坐标 |
| `model.version` | 可追溯的模型版本 |
| `inference_ms` | 单次推理耗时 |

## 后续演进路径

```text
MockInferenceBackend
  -> PyTorchInferenceBackend
  -> ONNXInferenceBackend
  -> TensorRTInferenceBackend
```

先完成合法数据来源、标注规范和评测方案，再接入模型权重。替换推理实现时必须保持接口协议不变。

## 浏览器 ONNX 说明

当前页面不使用 ONNX Runtime Web 或浏览器 Worker。未来加入浏览器本地推理时，应独立设计模型分发、Worker 串行队列、坐标还原、浏览器兼容性、真实结果校验与安全边界。
