# 11 测试与排错

## 前端检查

```powershell
cd frontend
npm.cmd test
```

该命令会先构建前端，再运行 HTML 渲染和关键交互约束测试。

## 后端检查

```powershell
cd backend
py -m py_compile app/main.py app/routers/inferences.py app/schemas/inference.py app/services/inference.py
py -m uvicorn app.main:app --reload --port 8000
```

打开 `http://127.0.0.1:8000/docs`，使用 Swagger 页面提交 JPG 或 PNG 测试接口。

## 接口连通性

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
```

应返回 `status: ok`。前端仍显示“后端待连接”时，检查环境变量和 CORS 配置。

## 常见问题

### PowerShell 不能运行 npm.ps1

使用 `npm.cmd install`、`npm.cmd run dev` 或 `npm.cmd test`。

### 页面显示“后端待连接”

- 确认后端命令仍在运行。
- 打开 `/health` 检查是否返回 200。
- 确认端口为 8000。
- 检查 `frontend/.env.local` 中的 `NEXT_PUBLIC_API_BASE_URL`。
- 修改环境变量后重启前端。

### 上传返回 415 或 413

415 表示文件不是 JPG/JPEG/PNG 或后缀不正确；413 表示图片超过 10 MB。前后端都会执行限制。

### 摄像头无法启动

使用 `localhost` 或 HTTPS 页面，在浏览器地址栏授权摄像头，并关闭可能独占摄像头的会议软件。当前只支持单帧检测。

## 提交前检查清单

1. 后端 `/health` 正常。
2. 单图、批量和摄像头截帧均能显示成功或失败。
3. 前端 `npm.cmd test` 通过。
4. 文档中的接口、端口和路径与代码一致。
5. 未提交数据集、模型权重、真实图片或密钥。
