# 05 前端开发指南

## 技术栈

- Next.js 16、React 19、TypeScript。
- Vinext 和 Vite：生成 Cloudflare Worker 兼容构建。
- 浏览器原生 `fetch`、`FormData`、`MediaDevices`、`LocalStorage`。

## 目录说明

```text
frontend/
  app/page.tsx        # 主应用和全部演示模块
  app/login/page.tsx  # 演示登录页
  app/globals.css     # 页面视觉与响应式规则
  public/             # 静态资源
  tests/              # HTML 渲染和客户端约束测试
  worker/index.ts     # Worker 入口
```

## 本地命令

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
npm.cmd run build
npm.cmd test
```

## 页面状态约定

| 状态 | 作用 |
| --- | --- |
| `selectedFile` | 当前单图待提交文件 |
| `imageUrl` | 浏览器本地预览地址 |
| `result` | 当前检测结果 |
| `records` | LocalStorage 演示追溯记录 |
| `backendOnline` | 后端 `/health` 连通状态 |
| `isSubmitting` | 单图、批量或摄像头提交中状态 |

## 接口请求规范

所有推理请求统一由 `requestInference` 发送：

```text
FormData
  file       图片文件本身
  threshold  0.10–0.95
  source     单图 / 批量 / 摄像头
```

不要只传文件名。请求失败时优先展示后端返回的 `detail`，便于用户了解格式、扩展名或大小限制。

## 新增页面流程

1. 确定页面属于工作台、检测、历史或模型模块。
2. 在 `app/page.tsx` 增加视图类型、导航项和独立页面片段。
3. 先定义 TypeScript 响应类型，再补充请求函数。
4. 为 loading、空状态、网络失败和权限失败提供文案。
5. 同步补充 `tests/rendered-html.test.mjs` 中的关键约束。

## 构建要求

提交前至少执行 `npm.cmd test`，该命令会运行前端构建和渲染测试。
