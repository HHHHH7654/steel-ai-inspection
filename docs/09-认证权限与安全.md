# 09 认证权限与安全

## 当前认证边界

`admin` / `admin123` 是仅用于现场演示的前端固定账号。登录状态保存在浏览器 SessionStorage，不包含真实用户表、密码哈希、JWT、角色、权限或服务端会话。

因此当前版本不能作为真实生产登录方案，也不应公开部署供真实用户上传图片。

## 当前安全措施

- 后端限制 JPG/JPEG/PNG、后缀和 10 MB 文件大小。
- 前端在提交前做相同的体验校验。
- 后端不写入上传图片，降低演示环境的数据残留风险。
- 本地 CORS 仅允许 `localhost:5173` 和 `127.0.0.1:5173`。

## 当前限制

- 不校验图片真实内容或像素尺寸。
- 无上传频率限制、用户身份和审计日志。
- 无 HTTPS、CSRF、文件病毒扫描或对象存储访问控制。
- LocalStorage 记录可被当前浏览器用户修改或清除。

## 生产化接入建议

```text
用户 -> 服务端登录 -> 密码哈希校验 -> JWT / 安全 Cookie
     -> 角色权限 -> 上传授权 -> 审计日志
```

至少实现：密码哈希、短期令牌或安全 Cookie、服务端权限判断、精确 CORS、HTTPS、上传频率限制、病毒扫描、对象存储私有读写和审计日志。密钥、数据库密码和 API Key 不能提交到 Git。
