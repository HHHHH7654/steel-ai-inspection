# 02 快速启动

## 环境要求

| 依赖 | 建议版本 | 用途 |
| --- | --- | --- |
| Node.js | 22 或更高 | 前端构建和开发服务 |
| Python | 3.10 或更高 | FastAPI 后端 |
| Chrome 或 Edge | 最新版 | 文件上传与摄像头演示 |

当前版本不需要 MySQL、Redis、Docker、数据集或模型权重。

## 安装依赖

```powershell
cd backend
py -m pip install -r requirements.txt

cd ..\frontend
npm.cmd install
```

使用 `npm.cmd` 是为了避免 Windows PowerShell 的脚本执行策略阻止 `npm.ps1`。

## 后端启动

```powershell
cd backend
py -m uvicorn app.main:app --reload --port 8000
```

启动后可访问：

- 健康检查：`http://127.0.0.1:8000/health`
- 接口文档：`http://127.0.0.1:8000/docs`
- 服务信息：`http://127.0.0.1:8000/api/v1/system/info`

## 前端启动

在另一个 PowerShell 窗口运行：

```powershell
cd frontend
npm.cmd run dev
```

通常访问 `http://localhost:5173`。页面顶部显示“Mock Inference 在线”表示前后端已连通。

## 后端地址配置

前端默认请求 `http://127.0.0.1:8000`。如需调整，复制 `frontend/.env.example` 为 `frontend/.env.local`，并修改：

```text
NEXT_PUBLIC_API_BASE_URL=http://你的后端地址:端口
```

修改后必须重新启动前端。

## 常见启动顺序

1. 启动后端并确认 `/health` 返回 `status: ok`。
2. 启动前端并打开浏览器地址。
3. 使用 `admin` / `admin123` 登录。
4. 上传 JPG 或 PNG 图片验证检测链路。
