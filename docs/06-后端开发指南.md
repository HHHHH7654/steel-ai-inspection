# 06 后端开发指南

## 技术栈

- FastAPI：HTTP 路由和 OpenAPI 文档。
- Pydantic：参数、响应和字段范围校验。
- Uvicorn：本地 ASGI 服务。
- python-multipart：解析浏览器上传的 `multipart/form-data`。

## 目录说明

```text
backend/app/
  main.py               # 应用创建、CORS、健康检查
  routers/inferences.py # 上传推理与系统信息接口
  schemas/inference.py  # Pydantic 模型
  services/inference.py # 推理实现
```

## 新增后端功能流程

1. 在 `schemas/` 定义请求或响应对象。
2. 在 `services/` 编写可独立测试的业务逻辑。
3. 在 `routers/` 校验 HTTP 输入并调用服务。
4. 在 `main.py` 注册路由和中间件。
5. 更新 [07-接口说明](07-接口说明.md) 和前端请求类型。
6. 用正常请求、错误格式、超大文件三类场景验证接口。

## 上传校验约定

后端必须检查：

- MIME 类型仅为 `image/jpeg` 或 `image/png`。
- 文件名后缀仅为 `.jpg`、`.jpeg` 或 `.png`。
- 文件内容不能为空。
- 文件大小不超过 10 MB。

前端校验只改善体验，不能替代后端校验。当前实现不写文件、不写数据库，也不会保留用户图片。

## 返回格式约定

推理响应核心字段：

```text
model.name / model.version
predictions[].class_name
predictions[].confidence
predictions[].bbox
inference_ms
mode
```

`bbox` 必须是 0–100 百分比坐标；修改字段名或改为像素坐标会破坏前端叠框逻辑。

## 配置规范

| 配置 | 当前默认 | 说明 |
| --- | --- | --- |
| 服务端口 | 8000 | Uvicorn 启动端口 |
| 允许前端地址 | localhost:5173 | 本地 CORS 白名单 |
| 最大上传大小 | 10 MB | 后端强制限制 |
| 推理模式 | mock | 仅演示，不代表真实模型 |

生产环境必须使用精确 CORS 白名单，不能开放任意来源。
