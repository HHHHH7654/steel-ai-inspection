# 01 项目总览

## 项目定位

SteelVision 是面向热轧钢带表面划痕检测场景的 Web 演示系统，展示图像采集、AI 检测、人工复核和困难样本候选统计的质量追溯闭环。

```text
图像输入 -> 文件校验 -> Mock 推理 -> 定位框展示 -> 人工复核 -> 本地追溯记录
```

它不是训练平台，也不是已投产的工业检测系统。所有结果均标记为 `mock`，不能用于宣称模型精度、召回率、实时帧率或生产质量结论。

## 当前核心能力

### 业务能力

- 固定演示账号登录。
- 单图上传、拖入预览与检测框展示。
- 批量选择最多 20 张图片并逐张调用后端。
- 浏览器摄像头单帧截取与检测。
- 人工确认、误检和漏检复核。
- 浏览器本地保存模型版本、阈值、耗时、结果和复核状态。

### AI 能力

- 后端根据统一协议返回可复现的 Mock 结果。
- 前端按 0–100 百分比坐标叠加 SVG 检测框。
- 已预留 `model`、`predictions`、`confidence`、`bbox` 等真实模型接入字段。

## 技术栈

| 层级 | 当前技术 | 作用 |
| --- | --- | --- |
| 前端 | Next.js、React、TypeScript、Vinext | 页面、图片预览、摄像头与结果展示 |
| 后端 | FastAPI、Pydantic、Uvicorn | 上传校验、Mock 推理、接口文档 |
| 数据 | 浏览器 LocalStorage | 演示记录临时保存 |
| 部署 | Cloudflare Worker 兼容前端构建 | 前端构建产物 |

## 代码目录

```text
frontend/  # 页面、静态资源、Worker 与前端测试
backend/   # FastAPI 应用、路由、模型和服务
docs/      # 项目与开发文档
data/      # 数据预留目录，当前不含数据
```
